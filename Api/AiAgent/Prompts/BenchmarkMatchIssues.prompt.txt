Тебе будут переданы два списка ошибок в тексте отчёта:
- список известных ошибок (каждая с номером `number`);
- список ошибок, найденных другим агентом (каждая с порядковым номером `index`).

Один и тот же дефект может быть описан разными словами, с разным приоритетом и с указанием
на разные строки. Твоя задача — понять, какая найденная ошибка соответствует какой известной.
Соответствие должно быть взаимно однозначным: одна найденная ошибка не может соответствовать
двум известным, и наоборот.

В ответе для каждой пары укажи:
`expectedNumber` - номер известной ошибки;
`foundIndex` - порядковый номер найденной ошибки;
`confidencePercent` - уверенность в сопоставлении от 0 до 100,
    где 100 — полное совпадение по смыслу и по месту в тексте,
    а 0 — ошибки описывают разные дефекты;
`reason` - краткое объяснение.

Пары с уверенностью ниже 60 не включай.
Ошибки, для которых соответствие не найдено, не включай в ответ.
ЕСЛИ ни одна найденная ошибка не соответствует известным, ВЕРНИ ПУСТОЙ СПИСОК (`[]`).
